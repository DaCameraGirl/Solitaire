**لعبة السوليتير الكلاسيكية كلوندايك، مباشرة داخل متصفحك.** اسحبي الأوراق
وأفلتيها، اختاري نمط أوراق اللعب، اختاري لون الطاولة، جرّبي مهمة تحدٍّ، والعبي
مع الموسيقى والصوت. من دون تثبيت، من دون بناء، من دون أي اعتماديات — فقط
HTML وCSS وجافاسكريبت خالص.

مباشر: [dacameragirl.github.io/Solitaire](https://dacameragirl.github.io/Solitaire/)

## المزايا

| الميزة | ماذا تفعل |
|---|---|
| **سحب وإفلات حقيقي** | التقطي الورقة وأفلتيها في مكانها الصحيح، من دون نقر ثم نقر |
| **الانتقال التلقائي إلى الأساس** | نقرة بسيطة على الورقة ترسلها مباشرة إلى ركيزتها إذا وُجد مكان صالح — الآص مثلاً يذهب إلى بيته وحده |
| **4 أنماط لأوراق اللعب** | كلاسيكي، ملكي (عاجي بخط مزخرف وعلامة مائية ذهبية)، بسيط، ونيون — يُحفظ اختيارك للمرة القادمة |
| **5 ألوان للطاولة** | أخضر لبادي، بنفسجي، كحلي، عنابي، وفحمي — تُحفظ أيضًا |
| **مهام التحدي** | السباق السريع (الفوز في أقل من 60 حركة)، بلا إعادة سحب (عدم إعادة تدوير ورق النفايات أبدًا)، سباق الآصات (وصول الآصات الأربعة إلى الركائز بحلول الحركة 15) |
| **الموسيقى والصوت** | موسيقى خلفية متكررة يمكن تشغيلها أو إيقافها، بالإضافة إلى مؤثرات صوتية عند السحب ووضع الورقة وحركة غير صالحة والفوز |
| **احتفال الفوز** | انفجار قصاصات ورقية وموسيقى احتفالية عند إنهاء اللوحة |

## طريقة اللعب

- اسحبي ورقة وأفلتيها على ركيزة أو عمود آخر لنقلها.
- نقرة بسيطة (من دون سحب) على ورقة ترسلها تلقائيًا إلى ركيزتها إذا وُجد مكان
  قانوني، وهذه أسرع طريقة للتخلص من الآصات والأوراق الصغيرة.
- تُرتَّب الأوراق في الركيزة تصاعديًا حسب نوعها، بدءًا من الآص.
- تنتقل الورقة إلى عمود آخر فوق ورقة بلون معاكس وبرتبة أعلى بواحدة (أو إلى عمود
  فارغ يبدأ بملك).
- انقري على كومة السحب لسحب ورقة إلى كومة النفايات؛ وانقري مجددًا عند فراغها
  لإعادة تدوير كومة النفايات إلى كومة السحب.
- الفوز يكون بنقل الأوراق الاثنتين والخمسين إلى الركائز الأربع.

## التشغيل محليًا

لا حاجة إلى أي تثبيت — افتحي ملف `index.html` مباشرة في المتصفح، أو شغّلي
المجلد عبر أي خادم ملفات ثابت:

```bash
python -m http.server 8000
```

ثم زوري `http://localhost:8000`.

## النشر

يقدّم GitHub Pages هذا المستودع مباشرة من جذر فرع `main` — من دون أي خطوة بناء،
لذا كل دفع (push) إلى `main` يُنشر تلقائيًا.
